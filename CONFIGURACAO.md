# Configuração

O admin usa Script Properties `ARQSELECT_ADMIN_USERNAME` e `ARQSELECT_ADMIN_PASSWORD_HASH`.
Sessões usam CacheService. A camada 2.0 usa ADMIN, ARQUITETO e FORNECEDOR.

Para produção, o cadastro de usuários deve ser feito por fluxo administrativo/convite e a criação de registros deve continuar no backend.
